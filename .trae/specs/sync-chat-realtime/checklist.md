# Checklist
- [x] 桌面端发起 AI 消息时，桌面端实时显示执行过程、过程输出和最终结果。
- [x] 桌面端发起 AI 消息时，移动端实时同步并显示执行过程、过程输出和最终结果。
- [x] 移动端发起 AI 消息时，移动端实时显示执行过程、过程输出和最终结果。
- [x] 移动端发起 AI 消息时，桌面端自动激活对应会话并实时显示执行过程、过程输出和最终结果。
- [x] 桌面端 assistant 消息在同时存在 `segments` 和 `text` 时不会丢失最终正文。
- [x] 移动端 assistant 消息在同时存在 `segments` 和 `text` 时不会丢失最终正文。
- [x] 两端过程段按 `stepId` 更新或合并，不重复堆叠同一过程。
- [x] done 事件不会覆盖或清空 pending 消息中已累积的 `text` 和 `segments`。
- [x] 历史会话重新打开后，两端都能恢复结构化过程和最终正文。
- [x] 用户界面不显示 `mobile sent message` 等内部调试状态。
- [x] 桌面端构建命令通过。
- [x] 后端测试命令通过。
- [x] 移动端可用静态检查通过，或记录当前环境下无法完成的具体原因：`dart analyze` 在当前环境启动后长时间无输出且不返回，已停止；未返回具体错误。
