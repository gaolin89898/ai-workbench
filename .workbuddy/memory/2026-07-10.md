## OpenCode / MiMo Code ACP 集成（桌面端聊天 + 模型选择）

发现 OpenCode 和 MiMo Code 都基于 ACP（Agent Client Protocol），`opencode acp`/`mimo acp` 通过 stdio JSON-RPC 通信，协议完全一致，可共用一套代码。本机已装 opencode 1.17.18、mimo 0.1.5。

ACP 对话流程（用 `.workbuddy/tmp/acp-probe.js` 实测验证）：
- `initialize`(protocolVersion:1) → `session/new`(cwd, mcpServers:[]) → 拿 sessionId + configOptions
- `session/prompt`(sessionId, prompt:[{type:"text",text}]) → 流式 `session/update` 通知（类型字段 `params.update.sessionUpdate`，值如 agent_message_chunk/usage_update）→ 最终 PromptResponse{stopReason, usage}
- 模型选择：`session/set_config_option`(sessionId, configId, value) —— configId 是 "model"/"effort"/"mode"
- 续接：`session/load`(sessionId, cwd, mcpServers:[])；取消：`session/cancel` 通知
- opencode：model + effort(low/medium/high/max，切换模型后才出现) + mode(build/plan)；开箱即用免费模型
- mimo：推理强度编在模型 value 后缀（mimo-auto/low/medium/high），无独立 effort；session/prompt 可能需登录

新建 `apps/desktop/src/main/acp.ts`（opencode/mimo 共用）：spawn `<provider> acp`(shell:true)，归一化 session/update 到 CodexTraceSnapshot。
