# CodeHub AI Brand Assets

This folder contains the source logo assets for CodeHub AI.

- `ai-workbench-mark.svg`: flat rounded-square logo mark for product UI, docs, and light/dark surfaces.
- `ai-workbench-app-icon.svg`: flat app icon source for launcher and installer exports.
- `ai-workbench-lockup.svg`: horizontal logo lockup for README, release pages, and marketing surfaces.
- `png/`: generated PNG exports in common sizes.

Design intent: the desktop and phone forms represent cross-device AI work, while the small spark and editor lines point back to the local coding workspace.
