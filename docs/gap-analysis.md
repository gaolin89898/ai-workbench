# AI Workbench 实用差距清单

> 自己用,说人话。抛开高大上概念,只列实际用起来会感觉缺的东西。
>
> 更新日期：2026-07-31 —— 原清单 6 项差距已全部落地，见各条 ✅ 标记。

## 一、实际会感觉缺的（已全部落地）

1. **聊天记录搜不到** ✅ 已实现（2026-07-30）——历史都在本机 SQLite 却没搜索。用一个月后想找"上次让 Claude 改登录的那次对话",翻不到。最常用,最该先补。
   - 落地：全文搜索（`searchAiSessions` IPC + SQLite FTS）、侧边栏搜索入口、弹窗搜索界面（`session-search-modal`）。
2. **AI 跑任务不敢离开** ✅ 已实现（notifications.ts）——Codex/Claude 跑长任务得盯着等结束,手机端断了重连看不到中间过程。实际感受就是"被拴在电脑前"。补个完成通知就能解放。
   - 落地：任务完成系统通知 + 更新前检测 AI 是否在运行（0.1.76）。
3. **切 provider 东西就乱** ✅ 已实现（2026-07-30）——Claude Code 改一半切到 Codex 试,Claude 那边改动没存档、回不去。实际用起来"不敢随便切"。
   - 落地：切换 Provider 时自动归档当前会话（`auto-archive session on provider switch`）。
4. **不知道花了多少钱** ⏳ 部分落地——多 provider 混用,月底看账单懵。各 CLI 各报各的,没总数。
   - 现状：后端已有 `TokenUsageSummary`（按工具聚合的 Token 用量,数据来自云端）+ 桌面端用量统计面板（设置 → 用量统计）+ 活动日历（0.1.93）。缺口：费用换算（Token → 金额）尚未实现。
5. **手机远程改代码心里没底** ✅ 已实现（2026-07-30）——让 AI 改代码,手机只能看终端文字,看不到具体改了啥就接受。改坏不知道。
   - 落地：移动端审批卡片展示文件 diff（`show diff in approval card`）。
6. **Git 只能看不能动手** ✅ 已实现（2026-07-30）——手机看到 branch 脏了,想 commit 还得回电脑。远程闭环不了。
   - 落地：桌面端和移动端 Git 操作（commit、分支等）。

2. **任务完成通知** ✅ 已完成 —— 系统通知。
3. **切 provider 前自动存档** ✅ 已完成 —— 自动归档会话。

其余（token 统计 ✅ 部分、diff 审查 ✅、git 操作 ✅）已跟进，剩余费用换算可后续补充。

## 三、差异化护城河（已经在用,守住）

- **手机远程控制桌面 AI 会话**:市面几乎空白,独此一家。
- **多 CLI 一个入口切**:Codex/Claude/OpenCode/DeepSeek 想用哪个用哪个。
- **完整历史留本机**:隐私在自己手里。
- **高危命令转发层拦截**:远程操作不慌。
