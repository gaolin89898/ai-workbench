# AI Workbench 实用差距清单

> 自己用,说人话。抛开高大上概念,只列实际用起来会感觉缺的东西。

## 一、实际会感觉缺的

1. **聊天记录搜不到**:历史都在本机 SQLite 却没搜索。用一个月后想找"上次让 Claude 改登录的那次对话",翻不到。最常用,最该先补。
2. **AI 跑任务不敢离开**:Codex/Claude 跑长任务得盯着等结束,手机端断了重连看不到中间过程。实际感受就是"被拴在电脑前"。补个完成通知就能解放。
3. **切 provider 东西就乱**:Claude Code 改一半切到 Codex 试,Claude 那边改动没存档、回不去。实际用起来"不敢随便切"。
4. **不知道花了多少钱**:多 provider 混用,月底看账单懵。各 CLI 各报各的,没总数。
5. **手机远程改代码心里没底**:让 AI 改代码,手机只能看终端文字,看不到具体改了啥就接受。改坏不知道。
6. **Git 只能看不能动手**:手机看到 branch 脏了,想 commit 还得回电脑。远程闭环不了。

## 二、先做这三件就够

1. **聊天记录搜索** —— 最简单、最常用、立刻见效
2. **任务完成通知** —— 让你能离开屏幕
3. **切 provider 前自动存档** —— 敢于随便切

其余(token 统计、diff 审查、git 操作)等这三件做完再说。

## 三、差异化护城河(已经在用,守住)

- **手机远程控制桌面 AI 会话**:市面几乎空白,独此一家。
- **多 CLI 一个入口切**:Codex/Claude/OpenCode/DeepSeek 想用哪个用哪个。
- **完整历史留本机**:隐私在自己手里。
- **高危命令转发层拦截**:远程操作不慌。
