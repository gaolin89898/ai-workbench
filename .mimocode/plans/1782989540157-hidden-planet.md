# Plan: 桌面端和移动端 - 记住密码功能

## 概述
为桌面端 (Electron/Vue) 和移动端 (Flutter) 添加"记住密码"功能，使用加密存储保护用户凭据。

---

## 桌面端 (Electron/Vue)

### 1. 新建 `src/main/credentials.ts`
- 使用 Electron 内置 `safeStorage` API 加密密码 (Windows 用 DPAPI)
- 存储路径: `app.getPath("userData")/saved-credentials.json`
- 文件格式: `{ email: string, encryptedPassword: base64-string }`
- 函数: `saveCredentials()`, `loadCredentials()`, `clearCredentials()`

### 2. 修改 `src/main/ipc.ts`
- 添加 3 个 IPC handler: `save_credentials`, `load_credentials`, `clear_credentials`

### 3. 修改 `src/services/desktop.ts`
- 在 `desktopApi` 对象添加 3 个方法

### 4. 修改 `src/main/sync.ts` — `logoutDesktop()`
- 退出登录时调用 `clearCredentials()`

### 5. 修改 `src/App.vue`
- 添加 `rememberPassword` ref 状态
- `onMounted`: 加载保存的凭据并填充
- `login()`: 根据勾选状态保存/清除凭据
- 添加"记住密码"复选框 UI + CSS
- `handleLogout()`: 重置复选框状态

---

## 移动端 (Flutter)

### 1. 修改 `pubspec.yaml`
- 添加依赖: `flutter_secure_storage: ^9.2.4`

### 2. 修改 `lib/services/api_client.dart`
- 添加静态方法: `saveCredentials()`, `loadSavedEmail()`, `loadSavedPassword()`, `hasSavedCredentials()`, `clearCredentials()`
- 使用 `FlutterSecureStorage` (Android KeyStore / iOS Keychain)

### 3. 修改 `lib/pages/login_page.dart`
- 添加 `_rememberPassword` 状态
- `initState()`: 加载保存的凭据
- `_login()`: 根据勾选状态保存/清除凭据
- 添加"记住密码"复选框 Row widget

### 4. 修改 `lib/pages/settings_page.dart`
- `_logout()`: 调用 `ApiClient.clearCredentials()`

## 验证方式

1. **桌面端**: 登录 → 勾选记住密码 → 退出 → 重新打开应用 → 检查凭据自动填充
2. **移动端**: 同上流程
3. **安全性**: 检查 `saved-credentials.json` 中密码是否为加密的 base64
4. **退出清除**: 退出登录后重新打开 → 确认凭据已清除
